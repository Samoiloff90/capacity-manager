CAPACITY PLANNER — пробный пакет Windows x64

В пакете: capacity-planner.exe, эта инструкция и manifest.json с версией,
состоянием исходников при упаковке и SHA-256 файлов. Рядом с ZIP поставляется
его контрольная сумма .sha256. Хеш проверяет целостность, но не заменяет
цифровую подпись и не доказывает происхождение программы из указанного коммита.

ТРЕБОВАНИЯ

Нужна Windows x64 с уже установленным Microsoft Edge WebView2 Evergreen Runtime.
WebView2 в этот архив НЕ включён. Наличие браузера Microsoft Edge само по себе
не является проверкой готовности среды. Пакет не устанавливает и не скачивает
runtime. Если его нет или корпоративная политика запрещает запуск, обратитесь
к администратору/ИТ-службе за разрешённой средой. Не отключайте защиту Windows,
антивирус или корпоративные ограничения ради запуска.

Это неподписанный пробный выпуск. Политика организации может запрещать его
запуск. Приложение запрашивает права текущего пользователя (asInvoker),
но наличие такого манифеста не подтверждает работу во всех корпоративных средах.
Первый запуск на чистой Windows без администратора не подтверждён. Данные о точной
версии находятся в manifest.json. Сборка для Mac — отдельный файл того же релиза.

Если SmartScreen покажет «Система Windows защитила ваш компьютер», нажмите
«Подробнее» → «Выполнить в любом случае», только если ZIP скачан со страницы
релиза https://github.com/Samoiloff90/capacity-manager/releases и его SHA-256
совпадает с опубликованным (проверка: Get-FileHash <путь к zip> в PowerShell). Если такой кнопки нет из-за политики организации,
не обходите запрет.

ЗАПУСК

1. Полностью распакуйте ZIP в отдельную доступную для записи локальную папку.
   Не запускайте EXE прямо внутри архива. Не заменяйте файлы работающей программы.
2. Запустите capacity-planner.exe обычным способом, без «Запуска от администратора».
3. Введите название команды и нажмите «Выбрать папку и создать».
   Выберите существующую пустую локальную папку для данных проекта.
   Для продолжения работы используйте «Открыть папку проекта».
4. Выберите год и квартал, нажмите «Создать квартал». Заполните «Команда»,
   «Календарь», «Отсутствия», «Распределение» и «Задачи».
   Встроенный календарь РФ есть для 2026 и 2027 годов. Для другого года явно подтвердите
   ручную проверку праздников и переносов.
5. Нажмите «Сохранить квартал», затем «Закрыть проект». Повторно откройте папку
   проекта и проверьте сохранённые данные. Начните с учебных, не рабочих данных.

Пустая оценка задачи означает «Нет оценки» и отличается от явно введённого 0.
При неполных оценках или сумме долей не 100% баланс предварительный.
Дефицит не запрещает сохранение; часы между направлениями автоматически
не перераспределяются. Общий остаток не доказывает достаточность компетенций.

ГДЕ ДАННЫЕ И КАК СДЕЛАТЬ КОПИЮ

Данные команды хранятся в выбранной папке проекта, основной файл — capacity.sqlite.
Они не входят в этот архив и не обязаны находиться рядом с EXE. У каждой команды
своя папка. Не открывайте один проект одновременно в нескольких экземплярах.

Не храните папку проекта в OneDrive или другой синхронизируемой папке: часто это
«Документы» и «Рабочий стол». Их содержимое выгружает в облако сама Windows, а не
приложение. Выберите локальную папку вне синхронизации, например папку Capacity в
вашей папке пользователя (%USERPROFILE%\Capacity).

Сначала сохраните квартал и закройте проект, затем скопируйте всю его папку
в отдельное место. Для переноса на другой компьютер также копируйте закрытую
папку целиком и открывайте её через «Открыть папку проекта». Это не синхронизация
и не объединение изменений. Не копируйте отдельно открытую SQLite-базу.

WebView2 использует служебный профиль/кеш в пользовательском каталоге данных
Windows (AppData). Он не является папкой проекта. Этот вариант поставки
не гарантирует отсутствие следов вне папки EXE и не является полностью
самодостаточным portable-пакетом: требуется системный WebView2.

СЕТЬ

В приложении нет сетевых функций: облачного входа, синхронизации, телеметрии,
загрузки ресурсов из интернета. Системный движок WebView2 может сам обращаться к
серверам Microsoft, например за настройками и обновлениями своих компонентов; это
допускается решением DEC-023. Требование к приложению: оно не передаёт данные
команды — имена, задачи, часы. Как это проверялось на Windows и macOS и что
получилось:
https://github.com/Samoiloff90/capacity-manager/blob/main/docs/audit/NETWORK_CHECK.md

Пока там нет результатов для вашей версии, начинайте с учебных данных. Не меняйте
защитные политики Windows ради использования пакета.

В этой версии есть выгрузка сохранённого квартала в отчёт Excel (XLSX); нет импорта
Excel/JSON, факта, спринтов и синхронизации.
При проблеме запуска сохраните текст ошибки и версию из manifest.json для
разбора с сопровождающим. Не отправляйте папку проекта, SQLite, логи профиля
или снимки с рабочими данными в публичные обращения.
