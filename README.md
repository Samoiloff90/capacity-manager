# Capacity Manager

Локальное desktop-приложение для квартального планирования capacity команды.
Целевая модель: одна команда — отдельная папка с SQLite; все расчёты и данные
остаются на компьютере. Стек: Tauri 2, React 18, TypeScript и SQLite.

## Текущая готовность

- В интерфейсе прототипа работает таблица команды: добавление, редактирование,
  удаление, поиск и фильтр участников. Остальные разделы пока преимущественно заглушки.
- Название команды меняется в разделе «Команда», сохраняется в SQLite и отображается
  в шапках всех разделов. Имя руководителя в шапке не используется.
- Новое квартальное расчётное ядро реализовано отдельно: ставка, календарь,
  отсутствия, направления, оценки задач и остаток/дефицит часов.
- Новое хранилище отдельных проектов реализовано и проверено на временных БД:
  атомарное сохранение, защита от устаревшей записи, повторное открытие и recovery.
- Новые расчёты и проекты ещё не подключены к основному пользовательскому сценарию.
  Действующий прототип использует прежнюю общую `capacity.db`, фиксированный Q2 2026
  и старый коэффициент производственной загрузки. Это не правила нового MVP.

В новой модели распределяются **все доступные часы**; встречи — отдельное направление.
Например, 20% от 100 доступных часов дают 20 часов, без предварительного вычета 30%.

## Запуск для разработки

Для разработки нужны Node.js/npm, Rust/Cargo и платформенные инструменты сборки
Tauri. Зависимости устанавливаются при подготовке среды; эта процедура может
требовать интернет. Работа готового приложения без сети проверяется отдельно.

Из корня проекта:

```powershell
npm ci
npm run tauri dev
```

`npm run dev` запускает только frontend; для работы SQLite нужен desktop-запуск Tauri.

## Проверки и сборка

```powershell
npm test
node node_modules/typescript/bin/tsc --noEmit
npm run build
cargo test --offline --manifest-path src-tauri/Cargo.toml
npm run tauri build -- --no-bundle
```

Флаг Cargo `--offline` требует заранее загруженных зависимостей.
Windows EXE после сборки: `src-tauri/target/release/capacity-planner.exe`.
Пользователю готового EXE не нужны npm и Rust; пригодность запуска зависит
от наличия WebView2 и политики компьютера. Portable-доставка на чистой Windows,
macOS и отсутствие исходящих соединений ещё не подтверждены.
