# Дополнения для Claude Code

- Цель: завершить MVP и выпускать сборки для Windows 10/11 x64 и macOS arm64
  (DEC-023). Основное использование — рабочий MacBook PO.
- Mac-сборка выполняется только в GitHub Actions (macOS arm64). На Windows .app не собрать,
  на Mac PO нет Xcode Command Line Tools: туда попадает только готовый .app.
  Без запуска на Mac не заявляй, что там что-то работает.
- Используй только искусственные данные. Никаким инструментом не открывай и не читай
  `*.sqlite*`, `*.db*`, `*.xls*`, в которых могут быть реальные данные: `clean.xlsx`,
  проекты и выгрузки PO. Запрет касается и `python`, `node`, `sqlite3`, `Get-Content`:
  правила доступа в `.claude/settings.json` их не перехватывают. XLSX, созданный тестом,
  проверяй в памяти теста.
- Порядок работы: каждый этап — план в Plan mode, затем «ок» PO, затем код.
  Push только после подтверждения PO, только выбранной ветки, без `--force`/`--all`.
  Ветки `local/*` и ссылки `refs/codex/*` не публикуются.
