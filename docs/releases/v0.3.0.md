**Пробная версия.** Третья сборка Capacity Planner для Mac и Windows.
- **Новое:**
  - компактный экран с итогами квартала;
  - копирование квартала;
  - число спринтов;
  - сохранение из окна «Несохранённые изменения» и по Ctrl+S / ⌘S;
  - пояснения терминов по значку (i).
- **Проверено на Windows:** сценарии на локальной сборке того же кода и проверка сети.
- **Проверено на Mac:** только запуск и выход на сервере GitHub. На Mac пользователя
  приложение ещё не проверялось — эту версию нужно проверить по чек-листу (ниже).

Начинайте с учебных данных. Если проверка на Mac пройдёт, этот же код выйдет как 1.0.0.

## Что нового в 0.3.0

- **Экран квартала.**
  - Шапка в одну строку: название команды меняется значком-карандашом.
  - Над вкладками — итоги квартала:
    - доступно команде;
    - потребность по задачам;
    - остаток после задач.

    Там же пометки «Предварительно» (есть задачи без оценки) и «Дефицит в N
    направлениях» со ссылкой на баланс.
- **Часы на экране:** «2 248 ч», «4,60 ч». Малый дефицит по-прежнему виден как «<0,01 ч».
  Отчёт Excel не изменился.
- **Новый квартал** создаётся кнопкой «Новый квартал…».
  - В поле «Скопировать из» можно выбрать сохранённый квартал. Переносятся сотрудники,
    ставки, компетенции, направления и доли.
  - Отсутствия и задачи не переносятся, календарь создаётся для нового периода.
- **Спринты:** 2 недели от первого понедельника квартала, в квартале 6 спринтов.
  - Спринт на стыке месяцев относится к месяцу, в котором заканчивается.
  - На вкладке «Календарь» — даты и рабочие дни каждого спринта и число спринтов по
    месяцам.
  - Часы спринта пока не считаются.
- **Несохранённые изменения:** кнопки «Сохранить и продолжить», «Не сохранять» и «Отмена».
  Если сохранить не удалось, переход не выполняется и видна ошибка с названием поля.
- **Ctrl+S (на Mac ⌘S)** сохраняет квартал.
- **Значок (i)** рядом с терминами объясняет, что такое бюджет, потребность, баланс,
  дефицит и другие.
- **Предупреждение о сумме долей** — только на вкладках «Распределение» и «Задачи». На
  вкладке «Распределение» — отметка, пока сумма не 100%.
- **Удаление** — значком корзины.
- **Исправлено:**
  - новый проект не создавался в папке со скрытым файлом Finder `.DS_Store`. Найдено в
    коде и проверено тестом; на Mac из-за этого проект в только что созданной папке мог
    не создаться;
  - папка без проекта при открытии давала системную ошибку, теперь — понятное сообщение;
  - F5 и Ctrl+R в Windows перезагружали окно: несохранённые правки терялись без вопроса, а
    проект оставался занятым до перезапуска. Теперь эти клавиши (на Mac — ⌘R) и меню
    страницы по правой кнопке отключены; в полях ввода меню с «Копировать» и «Вставить»
    осталось.

## Что внутри

- Проект команды в выбранной папке: сотрудники, компетенции, ставки, календарь РФ
  2026 и 2027 с ручными поправками, отсутствия, доли направлений.
- Задачи с оценками в часах, остаток или дефицит по направлениям.
- Выгрузка сохранённого квартала в отчёт Excel (XLSX).
- Всё хранится локально. Сетевых функций в приложении нет.

## Какой файл скачать

Файлы ниже, в разделе **Assets**. «Source code» — исходники, для запуска они не нужны.

| Компьютер | Файл |
| --- | --- |
| Mac на Apple Silicon (M1 и новее) | `Capacity-Planner-0.3.0-macos-arm64.zip` |
| Windows 10/11 x64 | `Capacity-Planner-0.3.0-windows-x64-system-webview2.zip` |

- `.sha256` — контрольные суммы архивов.
- `capacity-network-watch-macos.sh` — скрипт наблюдения за сетью на Mac (ниже).

## Запуск на Mac

1. Распакуйте архив. Если Safari распаковал его сам, `Capacity Planner.app` уже в «Загрузках».
2. Перенесите `Capacity Planner.app` в папку «Программы» в домашней папке
   (`~/Applications`; если её нет — создайте). Права администратора не нужны. Если там
   уже есть прошлая версия, замените её.
3. Откройте приложение. Если macOS сообщит, что приложение не открыто:
   1. нажмите «Готово»;
   2. откройте «Системные настройки → Конфиденциальность и безопасность»;
   3. нажмите **«Всё равно открыть»**.

   Другой способ — выполнить в «Терминале»:
   `xattr -dr com.apple.quarantine "$HOME/Applications/Capacity Planner.app"`.

Эти шаги описаны по документации Apple и на Mac пользователя ещё не проверялись. Сборка
подписана ad-hoc, без сертификата разработчика и нотаризации. Если политика ИТ запрещает
запуск, не обходите её.

## Запуск на Windows

1. Распакуйте ZIP целиком в отдельную локальную папку.
2. Запустите `capacity-planner.exe` без прав администратора. Нужен установленный WebView2.
3. SmartScreen может показать «Система Windows защитила ваш компьютер». Сначала проверьте
   SHA-256 архива по таблице ниже:
   - на Windows — `Get-FileHash <путь к zip>` в PowerShell;
   - на Mac — `shasum -a 256 <путь к zip>` в «Терминале».

   Только если сумма совпадает, нажмите «Подробнее» → «Выполнить в любом случае».

Подробности — `README-PORTABLE.txt` в архиве.

## Где хранить данные

Каждая команда — отдельная папка с файлом `capacity.sqlite`. **Не выбирайте папку внутри
OneDrive или iCloud Drive.** Часто синхронизируются «Документы» и «Рабочий стол»; их
содержимое выгружает в облако сама система, а не приложение. Подойдёт, например,
`~/Capacity` на Mac или `%USERPROFILE%\Capacity` на Windows.

Проекты версий 0.1.0 и 0.2.0 открываются без изменений: формат данных тот же.

## Сеть

Системный движок (WebView2 на Windows, WebKit на Mac) может сам обращаться к серверам
Microsoft или Apple. Это допускается. Приложение не должно передавать данные команды.
- **Windows:** метки данных команды в трафике не найдены. Одно соединение движка с сервером
  Microsoft нельзя проверить по содержимому.
- **Mac:** проверены только запуск и выход на сервере GitHub.

Методика и результаты:
[NETWORK_CHECK.md](https://github.com/Samoiloff90/capacity-manager/blob/main/docs/audit/NETWORK_CHECK.md).

Проверить у себя на Mac:
1. Закройте Capacity Planner, Safari и Mail.
2. Скачайте `capacity-network-watch-macos.sh` и выполните в «Терминале»:
   `bash ~/Downloads/capacity-network-watch-macos.sh`.
3. Поработайте в приложении с учебными данными и закройте его.
4. Скрипт сохранит отчёт рядом с собой. В нём только адреса и порты, без данных команды.

## Что ещё не проверено

- Работа на Mac пользователя, в том числе ⌘S, значки (i) и отключение перезагрузки
  окна (пункт 12 чек-листа). Чек-лист —
  [MACOS_BUILD.md](https://github.com/Samoiloff90/capacity-manager/blob/main/docs/audit/MACOS_BUILD.md#чек-лист-на-mac).
- Создание проекта в папке с `.DS_Store` на настоящем Mac. Проверено тестом.
- Запуск на чистой Windows без прав администратора и на Windows 10.
- Открытие отчёта в Excel for Mac.
