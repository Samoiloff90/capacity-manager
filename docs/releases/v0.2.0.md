**Пробная версия.** Вторая сборка Capacity Planner для Mac и Windows.
- **Новое:** встроенный производственный календарь РФ на 2027 год.
- **Проверено на Windows:** сценарии на локальной сборке того же кода и проверка сети.
- **Проверено на Mac:** только запуск и выход на сервере GitHub. На Mac пользователя
  приложение ещё не проверялось — эту версию нужно проверить по чек-листу (ниже).

Начинайте с учебных данных.

## Что нового в 0.2.0

- Календарь РФ 2027 для пятидневной недели по ст. 112 ТК РФ и постановлению
  Правительства РФ от 17.09.2026 № 1187.
  - Переносы: 2 января → 5 ноября, 3 января → 31 декабря, 20 февраля → 22 февраля.
  - Суббота 20 февраля — рабочий день.
  - Рабочих дней по кварталам: 56 / 62 / 66 / 63, за год 247.
- Квартал 2027 теперь создаётся без ручного подтверждения календаря. Источники видны на
  вкладке «Календарь» → «Источники календаря».
- Если квартал 2027 уже создан в версии 0.1.0 в ручном режиме, он остаётся ручным:
  сохранённый календарь при открытии не пересчитывается. Проверьте его дни на вкладке
  «Календарь».
- Сокращённые предпраздничные дни, как и раньше, считаются полными: 8 часов.

## Что внутри

- Проект команды в выбранной папке: сотрудники, компетенции, ставки, календарь РФ
  2026 и 2027 с ручными поправками, отсутствия, доли направлений.
- Задачи с оценками в часах, остаток или дефицит по направлениям.
- Выгрузка сохранённого квартала в отчёт Excel (XLSX).
- Всё хранится локально. Сетевых функций в приложении нет.

## Какой файл скачать

Файлы ниже, в разделе **Assets**. «Source code» — исходники, для запуска они не нужны.

| Компьютер | Файл |
| --- | --- |
| Mac на Apple Silicon (M1 и новее) | `Capacity-Planner-0.2.0-macos-arm64.zip` |
| Windows 10/11 x64 | `Capacity-Planner-0.2.0-windows-x64-system-webview2.zip` |

- `.sha256` — контрольные суммы архивов.
- `capacity-network-watch-macos.sh` — скрипт наблюдения за сетью на Mac (ниже).

## Запуск на Mac

1. Распакуйте архив. Если Safari распаковал его сам, `Capacity Planner.app` уже в «Загрузках».
2. Перенесите `Capacity Planner.app` в папку «Программы» в домашней папке
   (`~/Applications`; если её нет — создайте). Права администратора не нужны. Если там
   уже есть версия 0.1.0, замените её.
3. Откройте приложение. Если macOS сообщит, что приложение не открыто:
   1. нажмите «Готово»;
   2. откройте «Системные настройки → Конфиденциальность и безопасность»;
   3. нажмите **«Всё равно открыть»**.

   Другой способ — выполнить в «Терминале»:
   `xattr -dr com.apple.quarantine "$HOME/Applications/Capacity Planner.app"`.

Сборка подписана ad-hoc, без сертификата разработчика и нотаризации. Если политика ИТ
запрещает запуск, не обходите её.

## Запуск на Windows

1. Распакуйте ZIP целиком в отдельную локальную папку.
2. Запустите `capacity-planner.exe` без прав администратора. Нужен установленный WebView2.
3. SmartScreen может показать «Система Windows защитила ваш компьютер». Сначала проверьте
   SHA-256 архива по таблице ниже:
   - на Windows — `Get-FileHash <путь к zip>` в PowerShell;
   - на Mac — `shasum -a 256 <путь к zip>` в «Терминале».

   Только если сумма совпадает, нажмите «Подробнее» → «Выполнить в любом случае».

Подробности — `README-PORTABLE.txt` в архиве.

## Где хранить данные

Каждая команда — отдельная папка с файлом `capacity.sqlite`. **Не выбирайте папку внутри
OneDrive или iCloud Drive.** Часто синхронизируются «Документы» и «Рабочий стол»; их
содержимое выгружает в облако сама система, а не приложение. Подойдёт, например,
`~/Capacity` на Mac или `%USERPROFILE%\Capacity` на Windows.

## Сеть

Системный движок (WebView2 на Windows, WebKit на Mac) может сам обращаться к серверам
Microsoft или Apple. Это допускается. Приложение не должно передавать данные команды.
- **Windows:** метки данных команды в трафике не найдены. Одно соединение движка с сервером
  Microsoft нельзя проверить по содержимому.
- **Mac:** проверены только запуск и выход на сервере GitHub.

Методика и результаты:
[NETWORK_CHECK.md](https://github.com/Samoiloff90/capacity-manager/blob/main/docs/audit/NETWORK_CHECK.md).

Проверить у себя на Mac:
1. Закройте Capacity Planner, Safari и Mail.
2. Скачайте `capacity-network-watch-macos.sh` и выполните в «Терминале»:
   `bash ~/Downloads/capacity-network-watch-macos.sh`.
3. Поработайте в приложении с учебными данными и закройте его.
4. Скрипт сохранит отчёт рядом с собой. В нём только адреса и порты, без данных команды.
