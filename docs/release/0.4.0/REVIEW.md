# Выпуск 0.4.0 — замечания ревью (Codex)

Проверяемая версия, объём, команды и тестовые данные — [STATUS.md](STATUS.md). Требования —
утверждённые документы, на которые он ссылается; при расхождении документа и кода
замечание указывает оба места.

## Как записывать

Одно замечание — один раздел `### R-NNN. <коротко>` с полями:

- **Важность:** блокер / существенное / незначительное / вопрос.
- **Где:** `файл:строка`, экран или сценарий.
- **Что не так:** наблюдаемое поведение или дефект кода.
- **Как воспроизвести или почему это ошибка:** шаги на учебных данных, тест или рассуждение.
- **Ожидается:** со ссылкой на требование (DEC-…, раздел документа).
- **Статус:** открыто → ответ в [RESPONSES.md](RESPONSES.md) → исправлено в `<коммит>` →
  подтверждено ревьюером (или: отклонено с обоснованием, принято PO).

Блокеры B-1–B-6 из STATUS.md уже известны; повторять их не нужно, но дополнения к ним
записываются здесь со ссылкой на номер.

Реальные данные, пароли, токены и ключи в замечания не вносятся. Код во время ревью не
меняется.
