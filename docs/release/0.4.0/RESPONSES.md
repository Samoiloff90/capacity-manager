PO разрешил цикл исправлений и кандидат в релиз; стабильный выпуск не разрешён. Объём 0.4.0
заморожен: без загрузки .xlsx, интеграций, ИИ, нового UX и постороннего рефакторинга.
Решения PO по замечаниям:
- R-001, R-002, R-003, R-004 — исправить; R-005 — неоднозначный источник требует явного
  выбора, старые источники не переименовываются и не объединяются;
- B-1 — исправить существующий общий XLSX в этом выпуске, минимальный состав задан PO;
- R-006 — риск не принят: показать сценарий и исправить минимально и безопасно;
- Q-001 и условия использования — конкретная оценка, не формальное закрытие;
- кандидат `0.4.0-rc.1` для macOS с тестовым идентификатором, отдельно от 0.3.0.
