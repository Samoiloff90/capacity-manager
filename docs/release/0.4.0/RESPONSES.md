# Выпуск 0.4.0 — ответы и исправления

Ответы автора на замечания ревью ([REVIEW.md](REVIEW.md), `R-NNN`) и багрепорты QA
([QA.md](QA.md), `BUG-NNN`). Блокеры выпуска — [STATUS.md](STATUS.md) (`B-N`).

## Порядок

1. Пока идут ревью и QA, код не меняется.
2. После раунда — ответ на каждое замечание: принять, отклонить с обоснованием или вопрос
   PO. Принятые собираются в план исправлений; исправления начинаются после «ок» PO.
3. Одно исправление — отдельный коммит с номером замечания в сообщении; здесь — полный
   хеш коммита и проверки, которые прошли.
4. Закрывает замечание тот, кто его записал: ревьюер или QA после перепроверки.
5. После исправлений — новый проверяемый коммит в STATUS.md.

## Шаблон

```text
### R-NNN / BUG-NNN. <коротко>
Решение: исправить / не исправлять (почему) / вопрос PO
Исправление: <полный хеш коммита>, <что изменено>
Проверки: <команды и итог>
Статус: ждёт ответа / ждёт «ок» PO / исправлено, ждёт перепроверки / закрыто
```
