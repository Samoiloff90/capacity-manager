## Условия корпоративного использования — существенные положения

Составлено автором из документов проекта и проверок. **Не утверждено PO, согласования ИТ
и ИБ нет.** Отсутствие согласования не означает, что оно не требуется. Окончательный
текст — до стабильного выпуска.

### Установка и подпись

- **macOS:** `.app` с подписью ad-hoc, без Apple Developer ID и нотаризации. Gatekeeper
  может остановить первый запуск. Разовое «Всё равно открыть» допустимо, только если это
  разрешает политика устройства. Обход Gatekeeper и MDM не предлагается. На управляемом Mac
  установка может потребовать ИТ или подписанной сборки.
- **Windows:** portable ZIP без подписи кода и без установщика; SmartScreen может
  предупредить. Нужна системная WebView2 Runtime.
- **Происхождение файла** подтверждается только тем, что он скачан со страницы релиза
  GitHub, и совпадением SHA-256 с файлом `.sha256` релиза. Автоматических обновлений нет.
- **RC ставится рядом со стабильной 0.3.0** (тестовый идентификатор); rc.2 заменяет rc.1.
  Стабильные имя и идентификатор — перед окончательным выпуском, с отдельной проверкой
  установки.

### Хранение и резервные копии

- **Где данные.** Каждая команда — своя папка с файлом `capacity.sqlite`. В нём имена
  сотрудников, ставки, компетенции, даты отсутствий, работы, ссылки и комментарии.
- **Защита.** Приложение файл не шифрует; доступ определяют права ОС на папку и, если оно
  включено, шифрование диска (FileVault, BitLocker).
- **Совместная работа.** Сервера, синхронизации и совместной работы нет. Проект одновременно
  открывает одно приложение (`.capacity.lock`).
- **Резервные копии делает пользователь:** копия папки проекта при закрытом приложении.
  Программа сама копирует файл только при обновлении проекта 0.3.0 до нового формата.
  После обновления 0.3.0 этот проект не откроет; возврат — через копию.
- **Не класть папку проекта** в iCloud Drive, OneDrive и другие синхронизируемые папки.
- **Отчёт XLSX** — отдельный файл там, где его сохранил пользователь; дальше он живёт по
  правилам обращения с документами организации.

### Сетевые ограничения

- **Приложение само в сеть не обращается.** Телеметрии и интеграций (Kaiten, ИИ) нет.
  Тест «no network APIs» проверяет код.
- **Движки окна** — WebView2 на Windows и WKWebView на macOS — могут обращаться к Microsoft
  и Apple в фоне (DEC-023).
- **Windows, обнаруженные соединения:**
  - у процесса приложения внешних соединений нет;
  - у WebView2 — `config.edge.skype.com` (конфигурация Edge);
  - одно TLS-соединение WebView2 с адресом Microsoft вне NetLog.
- **Исследованный трафик.** В трафике, который записывает NetLog, меток данных команды нет,
  контрольная метка находится. Содержимое соединения вне NetLog не исследовано, поэтому
  безусловного вывода «данные не передаются» нет. QUIC на время проверки отключался.
  Холодный запуск без сети не проверен.
- **Mac пользователя:** сеть со сценарием не наблюдалась. На сервере GitHub — только
  простой без данных.
- **Подробности** — [NETWORK_CHECK.md](../../audit/NETWORK_CHECK.md).

### Известные риски

- Данные не шифруются приложением; потеря или копирование папки — потеря или утечка
  данных команды.
- Резервные копии ручные.
- Сборки не подписаны издателем.
- Содержимое одного соединения WebView2 не исследовано; Mac пользователя по сети не
  проверен.
- **Полномочия окна (Q-001)** в rc.2 ограничены: только выбранный проект и запросы самого
  приложения. Перепроверки Codex нет. Если в окне исполнится посторонний скрипт (такого
  пути не найдено), он может испортить данные кварталов открытого проекта, но не другие
  базы, не схему и не файлы вне проекта.
- Исправления циклов 1 и 2 не перепроверены Codex и QA.
- На Mac PO rc.2 не запускался. Восстановление после сбоя на APFS не проверено.
- Версия пробная (0.x, pre-release, DEC-025).

### Допустимые условия пилота (предложение автора, решает PO)

- **Сейчас** — только вымышленные данные.
- **Реальные данные** — не раньше, чем:
  - Codex и QA перепроверят rc.2;
  - PO проверит rc.2 на своём Mac;
  - ИТ и ИБ согласуют пункты ниже.
- **Круг пилота:** PO на своём рабочем MacBook, 1–3 команды.
- **Минимум персональных данных:** имя или рабочее обозначение, ставка, компетенции, даты
  отсутствий без причин.
- **Папка проекта** — на локальном диске с шифрованием диска, не в синхронизируемой папке.
  Копия папки — перед каждым обновлением приложения и регулярно.
- **Установка** — только из релиза GitHub со сверкой SHA-256. Сборка ad-hoc — только если
  политика устройства это допускает, иначе через ИТ.
- **Отчёты XLSX** — по правилам организации для внутренних документов.
- **Сообщения о сбоях** — без реальных данных и файлов проекта.

### Что требует согласования ИТ и ИБ

- Запуск на рабочем устройстве приложения без подписи издателя (Gatekeeper, MDM,
  SmartScreen).
- Хранение персональных данных сотрудников (имена, отсутствия) в локальном файле без
  шифрования приложением: допустимость, место хранения, сроки и удаление.
- Фоновые соединения WebView2 и WKWebView с Microsoft и Apple, включая соединение с
  неисследованным содержимым.
- Резервное копирование папок проектов и хранение отчётов XLSX.
- Использование pre-release версии из публичного репозитория GitHub.
