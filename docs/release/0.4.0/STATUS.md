Start-Process .\src-tauri\target\release\capacity-planner.exe

## Ограничения и условия корпоративного использования — черновик

Составлено из документов проекта, **не утверждено PO**.

- **Данные** — только локально, в папке проекта (`capacity.sqlite`), без шифрования: имена
  сотрудников, ставки, компетенции, даты отсутствий, работы, ссылки, комментарии. Доступ
  определяют права ОС на папку. Сервера, синхронизации и совместной работы нет. Проект
  одновременно открывает только одно приложение (`.capacity.lock`).
- **Резервные копии** делает пользователь: копия папки при закрытом приложении. Сама
  программа копирует файл только при обновлении проекта 0.3.0.
- **Папка проекта** — не в iCloud Drive, OneDrive и других синхронизируемых папках.
- **Совместимость.** Проект 0.3.0 обновляется до нового формата при первом сохранении,
  с копией. После этого 0.3.0 его не откроет; возврат — через копию
  ([v0.4.0-alpha.2.md](../../releases/v0.4.0-alpha.2.md) «Как сохранить 0.3.0 и вернуться к ней»).
- **Сеть.** Приложение само в сеть не обращается, телеметрии нет. Системный движок
  (WebView2, WKWebView) может обращаться к серверам Microsoft и Apple в фоне (DEC-023).
  Windows проверена ([NETWORK_CHECK.md](../../audit/NETWORK_CHECK.md)); одно соединение
  вне NetLog не проверено по содержимому. Mac пользователя не проверен.
- **Подпись.** macOS — ad-hoc, без Developer ID и нотаризации; Windows — без подписи.
  Обход Gatekeeper, MDM и SmartScreen не предлагается; на управляемом устройстве может
  понадобиться ИТ.
- **Нет:** загрузки файла .xlsx, Kaiten, ИИ. Ссылка на карточку хранится как текст и
  копируется.
- **Платформы:** Windows 10/11 x64, macOS 11+ на Apple Silicon (DEC-023).
- Согласование с ИТ и ИБ перед работой с реальными данными — решение PO.
