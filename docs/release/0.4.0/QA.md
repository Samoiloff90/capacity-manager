# Выпуск 0.4.0 — QA

Проверяемая версия, сборки, команды и тестовые данные — [STATUS.md](STATUS.md). Ожидаемое
поведение — в утверждённых документах, на которые ссылаются кейсы; здесь его не
переписываем. Кейсы — стартовый набор от автора: QA может добавлять, менять и снимать
кейсы с пояснением.

Только учебные данные: `…-demo-projects.zip` релиза (проекты `Alpha-new-format`,
`Beta-format-0.3.0`, шаблон `Import-template.xlsx`) или проекты, созданные в пустой папке.

## Как записывать

- **Результат:** PASS / FAIL (`BUG-NNN`) / BLOCKED (чем) / N/A. Пока кейс не проверен —
  «не проверено».
- **Где:** ОС и версия, сборка (имя файла и SHA-256 или коммит), дата.
- Ошибка — раздел в «Багрепортах» по шаблону ниже.
